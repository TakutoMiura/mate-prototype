# MATE その場旋回仕様（TURNING_SPEC）

- 版: 1.0
- 状態: 初回実装仕様確定（2026-11-02）
- 調整値: 操作確認済みの足先角度閾値を含む初期仕様値。将来変更時は本書とInspector既定値を同時に更新する。

## 1. 目的

MATE の停止状態における方向転換を、重量感のある二足歩行機械として表現する。

旋回は **「脚が先に動いて胴体を回す」動作ではない**。まず機体が目標方向へ回頭し、その結果として各脚の姿勢が崩れ、許容範囲を超えた脚だけが踏み替えによって位置を修正する。

小角度では足裏の軽微なスライドや脚の関節運動で吸収し、大角度では踏み替えを繰り返す。ゲーム中の機体位置を動かさず、あくまでその場で向きを変える。

本仕様は **停止旋回（turn in place）** を対象とする。移動しながらの歩行旋回、索敵・照準による上半身のみの回頭、攻撃時の姿勢制御は別仕様とする。

## 2. 用語と座標

- **機体ルート**：ゲームプレイ上の位置・向きを保持するノード。停止旋回中、ワールド座標の位置は不変とする。
- **機体中心 C**：停止旋回の回転中心となる、地面の水平面上の基準点。停止旋回中は固定。
- **機体向き θ**：ルートのヨー角。旋回要求に従って角速度制限付きで更新する。
- **理想足位置**：その時点の機体向きと通常の立ち幅から定まる、左右それぞれの足の目標位置（ワールド座標）。
- **実足位置**：現在描画されている足先の接地位置（ワールド座標）。接地保持／踏み替え中に別々に管理する。
- **足先向き**：各足のヨー角。足位置だけでなく、過大なねじれの検知に使う。
- **支持脚**：踏み替え中に接地を維持する側の脚。物理シミュレーション上の厳密な支持多角形は本仕様の必須要件ではない。

Godot の座標系・ノード構成に依存するローカル軸やモデル前方の符号は、実装側で既存モデルに合わせて統一する。本仕様の「右／左」は常に **MATE 自身から見た右／左** を意味する。

## 3. 不変条件

1. 停止旋回の開始から完了まで、**ゲームプレイ上の機体ルート位置と旋回中心 C は移動しない**。回転は許可する。
2. 胴体は目標方向に向かって角速度制限付きで回頭する。足のアニメーション完了を待ってから回頭を開始する方式にはしない。
3. 足先は胴体に単純に親子追従して回り続けるのではなく、ワールド座標での接地点／目標値を独立して管理する。
4. 足のずれが小さい間は、軽い接地スライドと関節角度の変化を許容する。**無制限に滑らせない**。
5. 許容値を超えた脚は、必要な側だけを持ち上げ、機体中心を基準とした新しい理想足位置へ踏み替える。
6. 原則として左右同時に大きく踏み替えない。踏み替え中は反対脚を接地させる。
7. 踏み替え時に機体ルートを目標足位置へ引っ張らない。脚の位置を直すために機体そのものを横移動させない。
8. 「右に曲がるなら必ず右脚から」という固定順序は採用しない。**実際の姿勢誤差と踏み替え必要度**で選ぶ。同程度なら旋回方向側の脚を優先してよい。

## 4. 理想足位置の定義

停止旋回の前後で脚幅が維持されるよう、機体中心 C を基準に各足の理想位置を算出する。

- `right_offset_local`：通常立位での右足位置（機体ローカル水平面）
- `left_offset_local`：通常立位での左足位置（機体ローカル水平面）
- `R(θ)`：水平面上のヨー回転

```text
ideal_right_world = C + R(θ) * right_offset_local
ideal_left_world  = C + R(θ) * left_offset_local
```

必要ならローカル前後オフセットも含める。上記は **最終的な接地位置の目標** を定義するものであり、足を毎フレームこの位置へ瞬間移動させる指示ではない。

理想足先向きは、基本的に現在の機体向き θ に揃える。モデルの足首構造によって許容される角度差はパラメータ化する。

## 5. 動作の流れ

### 5.1 回頭開始

1. 現在向きと目標向きの最短符号付き角度差を求める。
2. 開始閾値以上なら停止旋回状態に移る。
3. 機体ルート位置は固定し、向き θ のみ角速度上限以内で更新する。
4. 胴体や骨盤は関節・局所アニメーションにより、わずかな遅れや荷重移動を表現してよい。ただし移動用ルートはずらさない。

### 5.2 足の追従（踏み替え不要）

1. 胴体の旋回によって、足と関節の相対姿勢が変化する。
2. 接地足は現在のワールド位置をおおむね保ちながら、脚の関節で差を吸収する。
3. ごく小さな接地スライドや足先ヨー回転は許容する。
4. 理想位置との差・足先角度差が閾値を超えなければ、踏み替えは起こさない。

### 5.3 踏み替え開始

1. 各足について、理想足位置との差と足先向きの差を評価する。
2. 踏み替え開始閾値を超え、かつもう一方の脚が接地していれば、該当脚を選択する。
3. 踏み替え開始時点の足位置・向きを記録する。
4. 着地点は基本的に旋回中の理想足位置とする。継続旋回が予測される場合、着地時に見込まれる向きへの**小さな先読み**を許容する。ただし過大な先読みは禁止。
5. その脚の接地拘束を解き、足先を持ち上げる。

### 5.4 踏み替え中

1. 足先は開始位置から着地点へ移動する。軌道に持ち上げ高さを設け、地面を水平移動するだけのモーションを禁止する。
2. 踏み替え側の膝と股関節を屈伸させる。支持脚は接地を維持する。
3. 胴体の回頭は基本的に継続するが、踏み替え中だけ旋回速度を緩めてもよい。
4. 着地地点が旋回の進行で古くなった場合、更新は急激なワープではなく、着地点を滑らかに補正する。補正量には上限を設ける。
5. 着地後は接地状態へ戻し、必要なら軽微な沈み込み・荷重移動を表現する。

### 5.5 連続旋回と終了

1. 踏み替え終了後、左右の足の姿勢誤差を再評価する。
2. 目標向きまでまだ角度差があり、脚の誤差も閾値を超えるなら追加で踏み替える。
3. 旋回指示の角度差が終了閾値内に入り、進行中の踏み替えが完了したら停止旋回を終了する。
4. 停止時に足が大幅に不自然なら、最後に**位置を固定したまま**整地用の踏み替えを実施できる。微小なずれなら実施しない。

## 6. 踏み替え判定

最初の実装では、以下の二つを個別に判定すればよい。

```text
position_error = horizontal_distance(actual_foot_world, ideal_foot_world)
yaw_error      = absolute_shortest_angle(actual_foot_yaw, ideal_foot_yaw)

need_step = position_error > position_start_threshold
         OR yaw_error > yaw_start_threshold
```

踏み替え終了判定には、開始閾値より小さい終了閾値を用いる（ヒステリシス）。ノイズや境界付近で脚が小刻みに踏み替わることを防ぐ。開始時には短いクールダウンも設けてよい。

複数脚が同時に閾値超過した場合は、正規化した位置誤差と角度誤差などから優先順位を決め、**片側ずつ**動かす。

初期段階で厳密な IK を組む必要はない。ただし、見た目上の接地位置をワールド座標で管理し、胴体回転に対して脚を補償できる仕組みは必要。既存のボーン／関節表現に合わせて、簡易 IK、関節計算、アニメーション補正のいずれかを選ぶ。

## 7. 調整パラメータ

| パラメータ | 役割 |
|---|---|
| `turn_max_yaw_speed` | 胴体／機体ルートの最大旋回角速度 |
| `turn_start_angle` / `turn_finish_angle` | 旋回開始・終了の角度差（ヒステリシス） |
| `foot_position_start_threshold` | 位置のずれによる踏み替え開始閾値 |
| `foot_yaw_start_threshold` | 足先のねじれによる踏み替え開始閾値 |
| `foot_position_finish_threshold` / `foot_yaw_finish_threshold` | 踏み替え完了時の許容誤差 |
| `foot_slide_max_distance` | 接地中に許容する微小スライドの上限 |
| `step_duration` | 1回の踏み替え時間 |
| `step_lift_height` | 踏み替え中の足先の最大持ち上げ高 |
| `step_lookahead_angle` | 継続旋回を見込む着地点の先読み角度上限 |
| `step_target_correction_speed` | 踏み替え中に着地点を補正する最大速度 |
| `turn_speed_during_step_factor` | 踏み替え中の旋回速度倍率 |
| `step_cooldown` | 踏み替え連発を避ける待機時間 |
| `body_weight_shift_amount` | 支持脚側への視覚上の荷重移動量 |

値はInspectorから調整できる。以下の初回実装値を本仕様の基準値とする。

## 8. 状態遷移の概略

```text
IDLE
  └─ 旋回要求あり → TURNING
                       ├─ 脚誤差が閾値内 → 回頭継続／軽微な接地調整
                       └─ 脚誤差が閾値超過 → STEPPING(left or right)
                                                  ├─ 片脚を持ち上げ、移動、着地
                                                  └─ TURNING に戻り再判定

TURNING
  └─ 方向差が終了閾値内 → 必要な整地動作 → IDLE
```

状態は実装都合に合わせて統合・細分化してよい。ただし外から観測できる動作と不変条件は維持する。

## 9. 指示変更・例外ケース

- **旋回方向の途中反転**：現在の実足位置と新しい理想位置から再評価する。「右旋回中だったから右脚を必ず踏み替える」などの固定シーケンスを続行しない。
- **目標角がごく小さい**：脚を持ち上げずに向きだけ修正できる。
- **180°旋回**：片脚ずつ何度でも踏み替えてよい。両足同時に大回転／大移動しない。
- **踏み替え中に目標角が変化**：現在の踏み替えを不自然にキャンセルして瞬間移動させない。接地後に再評価することを基本とする。
- **移動命令に切り替わった場合**：接地と姿勢の整合性を維持したまま歩行状態に引き継ぐ。具体的な歩行とのブレンド方法は別仕様で決める。
- **斜面・段差**：本仕様は平坦地での成立を第一段階とする。地形追従は別途拡張する。

## 10. デバッグ表示

検証用に切り替え可能な表示を設ける。

- 機体中心 C とルート座標
- 各脚の実足位置（現在）と理想足位置（目標）
- 接地中／踏み替え中の脚の区別
- 各脚の位置誤差・角度誤差・踏み替え閾値
- 機体の現在向き・目標向き・角速度

可能であれば真上視点で足の軌道を見られることが望ましい。

## 11. 受け入れテスト

1. **右 10°**：ルート位置不変。足先角度差が40度を超えないため、踏み替えずに方向転換する。
2. **右 90°**：ルート位置不変。脚の姿勢誤差が増えた場合に片脚ずつ踏み替え、完了時に自然な脚幅へ戻る。
3. **左 90°**：右旋回の左右反転として成立する。脚選択が左固定でなくても自然であれば可。
4. **180°**：複数回の踏み替えを通じて旋回し、足先の過大なねじれが持続しない。
5. **右旋回途中で左へ指示変更**：旧方向の足運びを機械的に完遂せず、新しい姿勢差に応じて処理できる。
6. **小角度の往復入力**：閾値付近で足がばたつかない。
7. **停止／旋回中の位置確認**：ゲームプレイ上のルート座標に意図しない XZ 平面の移動が発生しない。
8. **片脚踏み替え中**：もう一方の足は概ね接地しており、踏み替える足は浮き上がる。過大な足裏スライドや足の瞬間移動がない。
9. **終了直後**：足が不自然な交差姿勢、極端な開脚、ねじれを残さない。

## 12. 非目標と実装方針

- 厳密な力学シミュレーション、実重心の移動計算、転倒判定は必須ではない。
- 実際の質量中心は荷重移動で多少動いてよいが、**ゲームプレイ上のルート／旋回中心の位置は固定**する。
- 特定のボーン階層、IK ソルバ、アニメーションツリー構造は本仕様では指定しない。
- Codex は先に既存モデル／ノード構造と現在の旋回処理を調査し、変更対象と検証手順を提示してから実装する。
- 本書は動作上の正とし、参考図解は姿勢変化の意図を共有するための補助資料とする。図と実装条件が食い違う場合は本書を優先する。
