# MATE小隊RTS — 受け入れテスト仕様（草案）

- 版: 0.2
- 各ケースは `Given / When / Then` 形式。数値未決のものは具体値を勝手に確定しない。
- 記号: **必須**=合意した期待挙動 / **暫定**=要確認の試験案

## A. 経路と小隊ポイント

| ID | 重要度 | Given / When / Then |
| --- | --- | --- |
| A01 | 必須 | 3機が移動中 / 1機が回避ダッシュ / 小隊ポイントが実位置に応じてずれ、次のウェイポイントへの接続経路だけが適切に補正される。ウェイポイントは動かない。 |
| A02 | 必須 | 移動中 / 小隊ポイント位置に機体がいない / 各機をポイントへ強制吸着させない。 |
| A03 | 必須 | 交戦開始 / 小隊ポイントを記録 / 交戦中に各機が動いても凍結座標は変わらない。 |
| A04 | 必須 | 交戦終了 / 3機が元の位置から散開 / 現存機の位置からポイントを再算出。旧交戦位置へ戻らず未達経路を再計画する。 |
| A05 | 必須 | プレイヤー指定ルートが障害物で遮断 / 通常進軍 / 勝手な大迂回はせずBLOCKED。 |
| A06 | 必須 | 自律戦闘で元経路から逸脱 / 交戦終了後の再計画でBLOCKED / この復旧用途に限り迂回を試みる。 |
| A07 | 暫定 | 復旧に非常に大きな迂回が必要 / 自動で目的地を変更せず、復旧失敗なら理由を表示。迂回限界は要決定。 |

| A08 | 必須 | 1機のみが著しく遊離 / 残る2機から小隊ポイントを算出 / 遊離1機が命令モードに関係なく合流経路へ移り、通常の攻撃行動は行わない。 |
| A09 | 暫定 | 3機が鋭角三角形 / 最小包含円算出 / 3機の座標が円周上、中心を小隊ポイントとする。方式採用確定後に必須化。 |

## B. 隊形と隘路

| ID | 重要度 | Given / When / Then |
| --- | --- | --- |
| B01 | 必須 | 3機で狭い通路に進入 / 一定のまとまりを維持しつつ1列等に収まり、横に広がって詰まらない。 |
| B02 | 必須 | 隘路で先行機が停止 / 後続が追いつく / 押し合い・振動・すり抜けが起きない。 |
| B03 | 必須 | 対向する小隊が狭路で遭遇 / 局所切り返し等で解消を試みるが、無理なすり抜けはしない。 |
| B04 | 必須 | 通路出口で先頭が交戦 / 後続が別の移動モードへ勝手に切り替わり、無期限に棒立ちにならない。 |

## C. 追撃とモード

| ID | 重要度 | Given / When / Then |
| --- | --- | --- |
| C01 | 必須 | ENGAGE中、目標が武器の有効射程内 / 自動追撃 / 必要以上に距離を詰めない。 |
| C02 | 必須 | HOLD中、目標が射程外 / 自発的な追撃を開始しない。 |
| C03 | 必須 | MOVE中 / 敵が視認可能かつ射程内に接近 / 注視・索敵は行うが一切攻撃せず、交戦アンカーを作らず、防御・回避しながら進軍する。 |
| C04 | 必須 | 交戦中、行動範囲の外に敵 / 追撃 / 無制限に追い続けない。 |
| C05 | 必須 | ENGAGEで交戦中の敵小隊が全滅し、最大射程＋余裕距離に他の敵がいない / 交戦終了 / 即座に経路進行を再開し、一定時間は警戒して接近敵を迎撃する。 |
| C06 | 必須 | HOLD中に回避で移動 / リロードや以降の位置調整 / 強制瞬間移動せず、小隊ポイント寄りに位置を回復しやすい。 |

## D. バーニア回避

| ID | 重要度 | Given / When / Then |
| --- | --- | --- |
| D01 | 必須 | MISS / 射手が単純に外す / 被弾側は回避しなくても無傷。 |
| D02 | 必須 | DODGE条件を満たし左右に空間あり / 攻撃を受ける / 瞬間噴射で実座標が横へ動き被弾しない。 |
| D03 | 必須 | 回避着地点または途中経路が塞がる / 回避要求 / 物体を貫通せず、盾等の代替防御へ移る。 |
| D04 | 必須 | 回避ダッシュ直後 / 通常制御に復帰 / 即座に元座標へワープしない。 |
| D05 | 必須 | 交戦中、回避要求がない / 時間経過 / 回避空間確保を理由に継続散開しない。 |

## E. バーニアジャンプ

| ID | 重要度 | Given / When / Then |
| --- | --- | --- |
| E01 | 必須 | 高台のウェイポイントとジャンプ接続がある / 進軍 / **歩行→接続点で短距離ジャンプ→着地→歩行**。 |
| E02 | 必須 | 高台に遠いウェイポイント / 進軍 / 現在位置から目的地へ直接大ジャンプしない。 |
| E03 | 必須 | 高さは低いがジャンプ禁止の壁 / 進軍 / ジャンプでは越えず、通行不能扱い。 |
| E04 | 必須 | ジャンプ接続あり、着地点が塞がる / 飛行前の検査 / 重複着地や貫通をしない。 |
| E05 | 必須 | ジャンプ実行中 / 通常移動・回避・隊形維持から新しい要求 / ジャンプの実座標更新を奪わない。 |
| E06 | 必須 | ジャンプ可能な段差 / 動作観察 / 離陸時に強噴射、着地直前に複数回制動噴射する。 |

## F. 既存戦闘への回帰

| ID | 重要度 | Given / When / Then |
| --- | --- | --- |
| F01 | 必須 | HITが発生 / 盾構え中 / 盾HPが減り、本体との二重ダメージなし。 |
| F02 | 必須 | MISSが発生 / 盾または本体 / いずれのHPも減らない。 |
| F03 | 必須 | 盾が破壊される / 次の被弾 / 盾防御不可、本体ダメージへ移る。 |
| F04 | 必須 | 回避・歩行・追撃が重なる / 戦闘継続 / 位置更新の競合・振動・急加速がない。 |
| F05 | 必須 | 敵を撃破 / ターゲット解放 / 破壊機を追い続けない。 |

## G. テスト用マップ・診断情報（実装提案）

- 平坦な射撃テスト場: 射程内停止、MISS/DODGE/BLOCK、戦闘終了時再計画。
- 狭路テスト場: 同方向の3機、対向通過、出口で交戦。
- 段差テスト場: ジャンプ可能接続、ジャンプ禁止壁、着地スペース不足。
- 経路復旧テスト場: 戦闘後に旧ルートから逸脱し、限定的復帰が必要。
- デバッグ表示候補: 小隊ポイント、交戦アンカー、各機の移動要求元、現在の移動実行状態、経路とジャンプ接続、BLOCKED理由。

## H. 合否の運用

1. 再実装前に最低限の通過条件と入力操作を確定する。
2. 追加機能ごとに既存ケースを再実施し、合否と再現条件を記録する。
3. 「機能が動いた」だけで合格にせず、上記**禁止挙動が起きない**ことを確認する。
4. 未決項目に依存する試験は、仕様確定まで保留にする。
