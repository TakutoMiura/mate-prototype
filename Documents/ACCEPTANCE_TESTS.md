# MATE小隊RTS — 受け入れテスト仕様（草案）

- 版: 0.14
- 各ケースは `Given / When / Then` 形式。数値未決のものは具体値を勝手に確定しない。
- 記号: **必須**=合意した期待挙動 / **暫定**=要確認の試験案

## A. 経路と小隊ポイント

| ID | 重要度 | Given / When / Then |
| --- | --- | --- |
| A01 | 必須 | 3機が移動中 / 1機が回避ダッシュ / 小隊ポイントが実位置に応じてずれ、次のウェイポイントへの接続経路だけが適切に補正される。ウェイポイントは動かない。 |
| A02 | 必須 | 移動中 / 小隊ポイント位置に機体がいない / 各機をポイントへ強制吸着させない。 |
| A03 | 必須 | 交戦開始 / 小隊ポイントを記録 / 交戦中に各機が動いても凍結座標は変わらない。 |
| A04 | 必須 | 交戦終了 / 3機が元の位置から散開 / 現存機の位置からポイントを再算出。旧交戦位置へ戻らず未達経路を再計画する。 |
| A05 | 必須 | プレイヤー指定ルートが障害物で遮断 / 通常進軍 / 勝手な大迂回はせずBLOCKED。 |
| A06 | 必須 | 自律戦闘で元経路から逸脱 / 交戦終了後の再計画でBLOCKED / この復旧用途に限り迂回を試みる。 |
| A07 | 暫定 | 復旧に非常に大きな迂回が必要 / 自動で目的地を変更せず、復旧失敗なら理由を表示。迂回限界は要決定。 |

| A08 | 必須 | 1機のみが著しく遊離 / 残る2機から小隊ポイントを算出 / 遊離1機が命令モードに関係なく合流経路へ移り、通常の攻撃行動は行わない。 |
| A09 | 必須 | 3機が鋭角・直角・鈍角三角形 / 小隊ポイントを算出 / 生存機の水平位置を含む最小包含円の中心とする。 |
| A10 | 必須 | 小隊を選択して地面を左クリック / 経路を確認 / 未到達ウェイポイントを置き換えて1点を設定し、小隊ポイントから経路が描画される。 |
| A11 | 必須 | 小隊を選択して複数回`Shift`＋左クリック / 経路を確認 / 各ウェイポイントが入力順に末尾へ追加される。 |
| A12 | 必須 | 小隊に経路を設定 / 平面移動を確認 / 生存機が目的地へ向き直る間はその場で旋回し、向きが揃ってから全機が同じ平面移動量で前進する。移動中は相対位置を維持し、小隊ポイントがウェイポイントから0.5以内に入ると次の点へ進む。隘路内のウェイポイントはB11に従う。未到達経路がなくなると停止する。初期速度は2.5ワールド単位/秒とする。 |
| A13 | 必須 | 進行方向が機体の向きと異なる地点へ指示 / 向きと位置を確認 / 最短角でその場旋回し、向きの差が5度以内になるまで前進しない。初期旋回速度は90度/秒とする。 |
| A14 | 必須 | 追加ウェイポイントを設定 / 次の区間への切替を確認 / 各機が次点へその場で向き直ってから進み、旋回中に隊形の相対位置を変えない。 |
| A15 | 必須 | 小隊が移動中 / `Space`を押す / 味方・敵・弾などシミュレーション対象の動作が停止し、カメラ操作・小隊選択・ウェイポイント設定は継続できる。もう一度`Space`を押すと移動が再開する。 |

## B. 隊形と隘路

| ID | 重要度 | Given / When / Then |
| --- | --- | --- |
| B01 | 必須 | 3機で狭い通路に進入 / 通路を通過 / 恒常的に横へ広がらず、必要時の局所退避以外で詰まらない。 |
| B02 | 必須 | 隘路で先行機が停止 / 後続が追いつく / 押し合い・振動・意図しないすり抜けが起きない。局所回避が必要ならB05に従う。 |
| B03 | 必須 | 対向する小隊が狭路で遭遇 / 局所切り返し等で解消を試みるが、無理なすり抜けはしない。 |
| B04 | 必須 | 通路出口で先頭が交戦 / 後続が別の移動モードへ勝手に切り替わり、無期限に棒立ちにならない。 |
| B05 | 必須 | 移動中に先頭機の前進経路だけが局所障害物で塞がる / 隊形移動を継続 / 先頭機が左右いずれかへ最大2機体幅まで退避し、通行可能な後続機は一時的な追い越しを含めて前進する。障害物通過後、空間があれば各機は小隊ポイント周辺へ徐々に戻り、押し合い・瞬間移動・恒常的な散開をしない。 |
| B06 | 必須 | 各機が隘路入口から異なる位置におり、一部は入口まで壁を回り込む必要がある / 隘路を通る経路を指示 / 各機の現在位置と機体幅に応じた歩行経路を計画し、入口に近い機体から順に進入する。 |
| B07 | 必須 | 小隊が一機ずつ通る隘路を進軍 / 後続機の移動を確認 / 後続機は不要な間隔を空けず先行機を追従し、停止した先行機への押し合い・重なり・すり抜けを起こさない。 |
| B08 | 必須 | 先行機が隘路を通過し、後続機がまだ通行中 / 出口付近を確認 / 先行機は後続機が通れる空間を残して待機し、生存機が全機通過してからウェイポイントへの進軍を再開する。 |
| B09 | 必須 | 小隊の一部が隘路内、他の機体が入口側にいる / 後方へ新しい経路を指示 / 各機の現在位置に基づき経路と進入順を見直し、衝突や閉塞を起こさず新しい経路へ進む。 |
| B10 | 必須 | テストフィールドの隘路を通る経路を指示し、壁の外側にも地面がある / 各機の経路を確認 / 壁の外側を大きく回って隘路を避けず、隘路内を通過する。ウェイポイントは変更しない。 |
| B11 | 必須 | 隘路内にウェイポイントを設定 / 小隊の動作を確認 / 生存機が衝突せず通路に沿って一列に整列して停止する。通路端に近い点では、全機が通路内に収まる位置へ列を寄せる。 |
| B12 | 必須 | 隘路内で整列中または整列後 / 隘路内への経路変更、出口方向への新しい経路、またはあらかじめ追加したウェイポイントを指示 / 各機の現在位置に応じて経路を組み直し、衝突や閉塞なく移動する。 |
| B13 | 必須 | 小隊ポイントからウェイポイントへの直線が隘路の側壁を横切り、B18・B20の操作補助にも該当しない / 経路を指示 / 勝手に隘路入口へ回り込まず、BLOCKEDと表示する。 |
| B14 | 必須 | 目的地が隘路の反対側付近にあるが、小隊ポイントからの直線は壁と隘路のどちらも横切らない / 経路を指示 / 隘路への進入を開始せず、通常の経路として進む。 |
| B15 | 必須 | 隘路の側方から通行したい / 壁を横切らず入口に至るウェイポイントと、入口を通って反対側へ進むウェイポイントを順に設定 / 指定順に進み、隘路で一機ずつ通行する。 |
| B16 | 必須 | 地形によって隘路がBLOCKED / 同じウェイポイントを再指定 / 現在の地形を再検査し、障害が残る場合はBLOCKEDを維持し、障害が除去されていれば通行を再開する。 |
| B17 | 必須 | 小隊が隘路を通行中 / 同じウェイポイントで経路を置き換える / 各機の現在位置から通行計画を作り直し、安全に通行を続ける。 |
| B18 | 必須 | 小隊が隘路内におり、出口の先に指定したウェイポイントへの直線が出口位置で開口部の端から1.0以内だけ外れる / 経路を指示 / ウェイポイントを変更せず、出口中央を経由する経路を表示し、その経路で目的地へ進む。Shiftで追加した経路も同様に表示・実行する。 |
| B19 | 必須 | 小隊が隘路内にいる / 直線が出口位置で許容幅を超えて外れる、補正幅が0、または補正後の出口からウェイポイントまでが地形で塞がれる / 自動で迂回せずBLOCKEDとする。 |
| B20 | 必須 | 小隊が隘路の外にいて、隘路内または反対側の出口の先を指定し、直線が入口および必要な出口の位置で開口部の端からそれぞれ1.0以内だけ外れる / 経路を指示 / ウェイポイントを変更せず、入口と必要な出口を経由する経路を表示して進む。Shiftで追加した経路も同様に表示・実行する。 |
| B21 | 必須 | 小隊が隘路の外にいる / 入口または出口でのずれが許容幅を超える、補正幅が0、または補正後の入口まで・隘路内・出口から目的地までが地形で塞がれる / 自動で大きく迂回せずBLOCKEDとする。 |
| B22 | 必須 | 複数の味方小隊に同時に隘路を通る経路を指示 / 各小隊を確認 / 進入権を得た1小隊だけが進入し、他の小隊は入口を塞がない脇の自動待機点へ移動する。先行小隊が全機通過すると待機小隊が進入し、それぞれ元のウェイポイントへ進む。 |
| B23 | 必須 | 味方小隊が隘路内で停止中 / 他の小隊に隘路を通る経路を指示 / 進入せず待機する。停止中の小隊が全機退出した後に進入する。 |
| B24 | 必須 | 自動待機点または隘路の経路補正点が生成される / 選択小隊の経路を確認 / 自動生成点が緑色で表示され、元のウェイポイントは変更されない。 |
| B25 | 必須 | 味方の通行を待つ間に小隊の各機が入口脇へ移動 / 進入権の解放後を確認 / 現在位置から入口に近い順に並び直し、緑の入口経由点を経て隘路を通り、元のウェイポイントへ進む。 |
| B26 | 必須 | 隘路の出口で先行機が集合位置へ移動中 / 後続機の動作を確認 / 先行機が出口を空けるまで後続機は進路を塞がず待ち、全機が衝突や停止の継続なく集合してから進軍する。 |
| B27 | 必須 | 隘路の出口付近に別小隊の停止機を配置 / 隘路を通過 / 停止機が安全な範囲で一時退避し、通過小隊は出口に集合して進軍する。退避機は通行後に安全な範囲で元の位置へ戻る。 |
| B28 | 必須 | 広い場所で別小隊の停止機が歩行を塞ぐ / 移動を継続 / 停止機は最大2機体幅以内で安全に退避し、通行後に安全な範囲で元の位置へ戻る。 |

## C. 追撃とモード

| ID | 重要度 | Given / When / Then |
| --- | --- | --- |
| C01 | 必須 | 基本DIRECTIVEを適用中、目標が武器の有効射程内 / 自動追撃 / 必要以上に距離を詰めない。 |
| C02 | 必須 | HOLD中、目標が射程外 / 自発的な追撃を開始しない。 |
| C03 | 必須 | MOVE中 / 敵が視認可能かつ射程内に接近 / 注視・索敵は行うが一切攻撃せず、交戦アンカーを作らず、防御・回避しながら進軍する。 |
| C04 | 必須 | 交戦中、行動範囲の外に敵 / 追撃 / 無制限に追い続けない。 |
| C05 | 必須 | 基本DIRECTIVEで交戦中の敵小隊が全滅し、最大射程＋余裕距離に他の敵がいない / 交戦終了 / 即座に経路進行を再開し、一定時間は警戒して接近敵を迎撃する。 |
| C06 | 必須 | HOLD中に回避で移動 / リロードや以降の位置調整 / 強制瞬間移動せず、小隊ポイント寄りに位置を回復しやすい。 |

| E11 | 必須 | 経路計算上有効なジャンプ接続の起点に到着 / 着地点枠の近くまたは中心に同じ小隊の機体がいる / 着地点候補を維持しながら占有機だけを安全に一時退避させ、空き次第ジャンプを実行する。退避を待つ間、経路はBLOCKEDにならず、退避後も目的地・着地枠を再計算でずらさない。退避不能時は理由をログに出す。別小隊の機体や他の予約が枠を塞いでいる場合は空くまで待ち、地形に塞がれている場合は理由付きでBLOCKEDになる。 |

| E13 | 必須 | 機体のジャンプ予定経路上に他の機体がいる / ジャンプを実行 / 塞がれた機体は飛行開始を待ち、経路が空くと順次ジャンプを再開する。 |

## G. テスト用マップ・診断情報（実装提案）

- 平坦な射撃テスト場: 射程内停止、MISS/DODGE/BLOCK、戦闘終了時再計画。
- 狭路テスト場: 同方向の3機、対向通過、出口で交戦。
- 段差テスト場: ジャンプ可能接続、ジャンプ禁止壁、着地スペース不足。
- 経路復旧テスト場: 戦闘後に旧ルートから逸脱し、限定的復帰が必要。
- デバッグ表示候補: 小隊ポイント、交戦アンカー、各機の移動要求元、現在の移動実行状態、経路とジャンプ接続、BLOCKED理由。

## H. 合否の運用

1. 再実装前に最低限の通過条件と入力操作を確定する。
2. 追加機能ごとに既存ケースを再実施し、合否と再現条件を記録する。
3. 「機能が動いた」だけで合格にせず、上記**禁止挙動が起きない**ことを確認する。
4. 未決項目に依存する試験は、仕様確定まで保留にする。

## K. 歩行モーション

| ID | 重要度 | Given / When / Then |
|---|---|---|
| K01 | 必須 | 小隊に経路を設定し、機体が前進する / MATEの動きを確認 / 接地・支持・遊脚・押し出しが交互に続き、接地時にごく短い溜めを作ってから次の一歩へ移る。歩幅が見て取れ、上半身が歩行中に前傾する。前脚と腰が逆方向へ捻れ、上半身は腰に対してさらにカウンター回旋する。 |
| K02 | 必須 | MATEが歩行中 / 接地と荷重移動を確認 / 重心が支持脚側へ移り、接地時にわずかに沈み込む。腕は前脚と逆側が前へ出るが、武器腕・盾腕を大きく振り回さず、装備の慣性を小さく保つ。 |

| K04 | 暫定 | 第一・第二小隊を個別に選択し、同等のウェイポイントをそれぞれ設定 / 2つの小隊を観察 / 命令は各選択小隊だけに適用され、同等の移動条件で棒人間と胸部突出型箱メカの形状差および腰と逆向きの胸部回旋を比較できる。 |
| K06 | 暫定 | 停止中の棒人間・箱メカを横または斜めから確認 / 初期姿勢を観察 / 膝が前方へ出て太ももとすねの向きが明確に変わり、足先はほぼ水平を保つ。肘を曲げた手先が前方へ出て、脚を伸ばし切った直立姿勢に見えない。 |
