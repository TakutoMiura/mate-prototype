# MATE小隊RTS — 操作仕様（草案）

- 版: 0.2
- この文書が目標とする操作体系の規範であり、現行コードのキー割当を仕様の根拠としない。
- **[確定]** 操作目的が合意済み / **[提案]** キー・ボタン割当は変更可能 / **[未決]** 詳細未確定。

## 1. 入力の原則 [確定]

- プレイヤーは小隊単位で命令する。個別機体を操縦しない。
- 複数小隊を切り替え、それぞれに独立した経路・交戦方針を与えられる。
- 左クリックの経路指定とカメラ操作は衝突しない。
- 戦術ポーズ中も小隊選択、経路編集、カメラ操作をできるようにする。
- UI操作中に地面への誤命令を出さない。

## 2. 操作割当の草案 [提案]

| 操作 | 候補入力 | 備考 |
| --- | --- | --- |
| 小隊1/2/3の選択 | `1`/`2`/`3` | 固定的な小隊数の拡張方法は未決 |
| 地面へ移動指示 | 左クリック | 選択小隊の経路入力。選択と移動のクリック関係は要確認 |
| ウェイポイント追加 | `Shift`＋左クリック | 既存の経路の末尾へ追加 |
| カメラ平行移動 | `W/A/S/D` | 地面基準。画面向きに合わせる |
| ズーム | マウスホイール | 最小最大距離を設ける |
| カメラ回転 | 中ボタンドラッグ | 水平・垂直角度。俯角を制限 |
| 選択小隊へフォーカス | `F` | 追尾するか一時的に寄るかは未決 |
| 初期視点へ復帰 | `Home` | 初期位置・角度・ズーム |
| 戦術ポーズ | **未決** | ポーズ中も命令とカメラは使用可能 |
| MOVE/DIRECTIVE/HOLD切替 | **未決** | 共通ディレクティブライブラリから小隊ごとに選択する。具体的な操作は要決定 |
| 標的指定 | **未決** | ディレクティブとの優先関係を定義する |

## 3. 入力結果の可視化 [確定／詳細未決]

- 現在選択中の小隊・命令方針・ウェイポイント列を判別できるようにする。
- ROUTE BLOCKEDでは理由を示す。
- MOVEで索敵中の目標注視は、攻撃命令と混同しない表示にする。

- カメラ追従・視点リセットの詳細。
