# MATE小隊RTS — 操作仕様（草案）

- 版: 0.4
- この文書が目標とする操作体系の規範であり、現行コードのキー割当を仕様の根拠としない。
- **[確定]** 操作目的と本書で確定したキー割当 / **[調整可能]** カメラ操作の初期数値 / **[未決]** 詳細未確定。

## 1. 入力の原則 [確定]

- プレイヤーは小隊単位で命令する。個別機体を操縦しない。
- 複数小隊を切り替え、それぞれに独立した経路・交戦方針を与えられる。
- 左クリックの経路指定とカメラ操作は衝突しない。
- 戦術ポーズ中も小隊選択、経路編集、カメラ操作をできるようにする。
- UI操作中に地面への誤命令を出さない。

## 2. 操作割当 [一部確定]

| 操作 | 入力 | 備考 |
| --- | --- | --- |
| 小隊1/2/3の選択 | `1`/`2`/`3` | 確定。選択時は小隊パネルとカメラフォーカスを更新 |
| 経路を設定 | 地面を左クリック | 確定。選択小隊の未到達ウェイポイントを置き換える |
| ウェイポイント追加 | `Shift`＋左クリック | 確定。選択小隊の経路末尾へ追加 |
| カメラ平行移動 | `W/A/S/D` | 確定。地面基準で画面向きに合わせる |
| ズーム | マウスホイール | 確定。距離範囲内で段階的に拡大・縮小 |
| カメラ回転 | 中ボタンドラッグ | 確定。水平・垂直方向に回転し、俯角を制限 |
| 選択小隊を追尾 | `F` | 確定。選択中小隊ポイントを継続して追う |
| 初期視点へ復帰 | `Home` | 確定。初期位置・角度・ズームへ滑らかに戻る |
| 戦術ポーズ | **未決** | ポーズ中も命令とカメラは使用可能 |
| MOVE/DIRECTIVE/HOLD切替 | **未決** | 共通ディレクティブライブラリから小隊ごとに選択する。具体的な操作は要決定 |
| 標的指定 | **未決** | ディレクティブとの優先関係を定義する |

## 3. 入力結果の可視化 [確定／詳細未決]

- 現在選択中の小隊・命令方針・ウェイポイント列を判別できるようにする。
- ROUTE BLOCKEDでは理由を示す。
- MOVEで索敵中の目標注視は、攻撃命令と混同しない表示にする。

## 4. カメラ操作の暫定初期値 [調整可能]

以下の数値は初回操作確認用の初期値であり、ゲームバランスや最終操作感を固定しない。テストフィールドのカメラ設定から調整できる。

| 項目 | 初期値 |
|---|---:|
| 平行移動速度 | 12 ワールド単位/秒 |
| ズーム距離 | 8〜60 ワールド単位 |
| ホイール1段の倍率 | 1.12 |
| 回転感度 | 0.005 ラジアン/ピクセル |
| 俯角 | 15〜75度 |
| 小隊フォーカス時の距離 | 14 ワールド単位 |

WASD、中ボタンドラッグ、ズーム操作を行うと小隊追尾を解除する。小隊パネルのクリックによるフォーカスは一度だけ寄り、`F` は追尾を開始する。`Home` は追尾を解除して初期視点へ戻す。
