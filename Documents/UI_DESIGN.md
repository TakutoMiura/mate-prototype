# UIデザイン仕様書

## 1. 文書情報

- 対象：フロントミッションオルタナティヴ風自主制作
- 対象画面：MATE運用画面
- 状態：暫定仕様
- 用途：MATE運用中の小隊・機体状態表示、操作、通信表示の共通指針

本書は現時点で合意した内容を整理した暫定仕様である。数値、判定基準、色などに「暫定」とある項目は、実装や画面確認を通じて変更される可能性がある。未決事項は第8節にまとめる。

## 2. デザイン方針

画面は、産業機械向け製品管理ソフトをモンテロ重工がMATE管制用に転用したような、実務的で情報密度の高いUIを基調とする。装飾を抑え、機体と小隊の稼働状態、操作内容を素早く読み取れることを優先する。

画面下部には通信欄を設け、運用中の通信やセリフを表示する。細かな意匠や演出は今後調整する。

## 3. MATE運用画面の構成

- **上部：小隊パネル** — 3小隊分を横並びで表示する。各パネルは小隊単位の状態と操作の入口を兼ねる。
- **中央：現場カメラ** — 選択中の小隊に応じてカメラの注目位置を切り替える。未接続時は `CAMERA OFFLINE` と表示する。戦闘シミュレーション未接続の開発段階では、Resourceサンプルを使った静的なテストフィールドを表示できる。
- **下部：通信欄** — 通信・セリフを表示する。

## 4. 小隊パネル

### 4.1 表示内容

各小隊は3機編成とし、小隊パネルに所属する3機それぞれの情報を表示する。搭乗者は顔アイコンで識別し、機体名のテキストは表示しない。

- 機体の顔アイコン
- HPゲージ
- 盾HPゲージ
- バックユニットの残弾ゲージ
- ディレクティブ選択欄

各ゲージは残量を長さで示し、ゲージ中央に「現在値/最大値」を文字で表示する（例：`120/300`）。数値を併記し、割合と実数の両方を読み取れるようにする。

### 4.2 小隊選択とカメラ

小隊パネルを選択すると、その小隊を選択状態にする。戦場カメラは選択小隊の小隊ポイントへフォーカスする。

選択中の小隊パネルは、背景色を変えず、パネル外周の枠線だけで示す。選択枠は白色 `#F0F3F5`、太さ3pxとする。

選択中の小隊に限り、所属する各MATEの胴体中央からリーダー線を伸ばし、小さな情報ウィンドウを表示する。ウィンドウは各機の投影シルエット上端より上に、編隊に沿って横並びで配置する。上側の表示領域が足りない場合は機体の下側へ移し、機体に重なる範囲を抑える。内容はユニット番号、機体HPバー、盾HPバーとし、HP数値と残弾表示は含めない。ウィンドウ背景色は小隊パネルの状態色、HP・盾HPバーは同パネルの緑色ゲージに合わせる。状態値は小隊パネルと同じ機体状態を参照する。

3Dモデルに常時表示していた機体名・機体種別・積載重量のラベルは表示しない。

### 4.3 選択機体の状態表示

上記のワールド内ウィンドウは選択小隊の変更に追従し、選択されていない小隊の機体には表示しない。カメラ移動中もリーダー線とウィンドウを機体に追従させる。表示項目や色の基準はこの節に定め、受け入れ条件J12で確認する。

### 4.4 ディレクティブの選択

共通ライブラリは `DirectiveLibrary` Resource として保持し、複数の `DirectiveDefinition` を登録できる。戦場UIでは登録済みライブラリから各小隊が使用するディレクティブを選択し、即時に適用する。ライブラリへの登録は機体・装備換装と同様の準備機能として別画面で扱う予定であり、戦場UIには追加操作を設けない。登録機能は `DirectiveLibrary.register_directive()` として再利用可能にする。名前はライブラリ内で重複不可とし、登録時に一意な識別子を自動採番する。初期の基本ディレクティブは常にライブラリに含める。

- `HOLD`
- `MOVE`
- 作成済みのディレクティブ（複数）

基本ディレクティブの動作は、旧ENGAGE仕様の交戦・射撃・必要な追撃とする。登録したディレクティブも現段階ではこの基本動作プロファイルを使用する。条件・行動の編集UI、一覧の並び順は未決とする。

プレビュー用ライブラリでは `BASIC DIRECTIVE` を基本動作の表示名として使用する。製品内ライブラリでの初期登録名は未決とする。

## 5. 小隊の消耗状態

- **合意（2026-10-30）**：大破は機体の現在HPが0以下の状態とする。
- **合意（2026-10-30）**：所属機が0機の小隊もパネル枠を維持し、通常の状態色判定を行わず、操作不能な無効状態として表示する。
- **合意（2026-10-30）**：0機小隊には `NO UNIT` と表示し、クリックによる選択はできない。
- **合意（2026-10-30）**：最大HPと最大盾HPの合計が0の機体は、残存率を `N/A` と表示し、残存率の閾値判定対象から除外する。大破数・盾全損数の判定は別途行う。
- **合意（2026-10-30）**：warning/criticalの状態は背景色だけで示し、状態名ラベルやアイコンを追加しない。
- **合意（2026-10-30）**：最大盾HPが0の盾未装備機は盾全損数に含めない。

小隊パネルの背景色で小隊全体の消耗状態を示す。状態色の判定は次の順で行い、**赤（critical）を黄（warning）より優先**する。

### 5.1 赤：critical

次のいずれかを満たす場合は赤状態とする。

- 2機以上が大破
- 小隊内の全機について、HPと盾HPを合算した残存率が40%未満

### 5.2 黄：warning

赤状態に該当せず、次のいずれかを満たす場合は黄状態とする。

- 1機が大破
- 2機以上の盾HPが全損（最大盾HPが1以上で、現在盾HPが0以下。盾未装備機は数えない）
- 小隊内の全機について、HPと盾HPを合算した残存率が70%未満

### 5.3 通常状態

赤・黄のいずれにも該当しない場合は通常状態とする。

### 5.4 残存率

各機の残存率は、HPと盾HPの最大値の合計に対する現在値の合計で算出する。

```text
残存率 = (現HP + 現盾HP) / (最大HP + 最大盾HP)
```

「全機の残存率が70%未満／40%未満」は、小隊の残存率を計算できる機体すべての残存率が該当閾値を下回っていることを指す。最大HPと最大盾HPの合計が0の機体はこの判定から除外する。判定対象が0機なら残存率条件は成立しない。閾値と同値（ちょうど70%または40%）は「未満」に含めない。

## 6. 色・枠線・形状（暫定）

| 用途 | 色コード | 備考 |
|---|---|---|
| 通常小隊背景 | `#30566B` | 通常状態 |
| 消耗注意背景（warning） | `#806A32` | 黄状態 |
| 危険背景（critical） | `#813D40` | 赤状態。warningより優先 |
| 選択枠・基本文字色 | `#F0F3F5` | 選択枠は白系 |
| パネル面 | `#202C33` | 基本サーフェス |
| HP・盾HPゲージ充填 | `#69B85A` | 緑系。暫定色 |
| 残弾ゲージ充填 | `#91B8C5` | 暫定色 |
| ゲージ未充填部 | `#080C0E` | 黒系背景 |
| ゲージ文字（充填部上） | `#080C0E` | 黒文字 |
| ゲージ文字（未充填部上） | `#F0F3F5` | 白文字 |

- パネルの角丸：4px
- 通常枠線：1px
- 選択枠線：3px、`#F0F3F5`
- 選択状態は枠線のみで表現し、状態背景色との併用を維持する。
- HP・盾HPゲージは緑系、残弾ゲージは青系の充填色で残量を示す。数値はゲージ中央に表示し、緑の充填部上では黒文字、黒い未充填部上では白文字とする。文字が充填境界をまたぐ場合は境界で文字色を切り替える。
- 機体名のテキストを表示せず、顔アイコンとゲージだけを配置する。
- 顔アイコンは28px角、機体行は高さ44px、ゲージは高さ14px・数値10pxを初期値とする。
- 通信欄は高さ50pxを初期値とする。
- 上部小隊パネルと中央戦場の高さ配分は1.6:4.4を初期値とし、戦場表示を広く確保する。
- 画面上下余白を8px、主要領域間隔を6pxとする。

色コード、寸法、余白、領域比率、枠線、角丸はすべて暫定値とする。コントラストや実画面での視認性を確認して調整する。

## 7. 通信欄

画面下部に発話者アイコンと最新の通信・セリフ1件を表示する領域を設ける。履歴アイコンを押すと、そのミッション中の全通信・セリフを発話者アイコン付きで表示する。履歴はスクロール可能とする。産業機械の管制コンソールに表示される通信ログを思わせる、簡潔で読みやすい見せ方を基本とする。

発話者アイコンと履歴アイコンは暫定デザインで実装し、共通アイコンデザイン導入時に差し替えるTODOとする。アイコン画像が指定されない通信には共通プレースホルダーを表示する。話者名・時刻・通信種別の表記は未決とする。

## 8. 未決事項

以下は本書では決定していない。暫定仕様を確定・更新する際に別途決める。

- **ゲージの個別色・寸法**：HP、盾HP、残弾それぞれの色や長さ。初期の高さ・文字サイズから調整する可能性がある。
- **ディレクティブ編集**：条件・行動の具体的な定義方法、一覧の並び順と編集画面。ライブラリ登録画面は機体・装備換装と合わせた準備機能として後続検討する。
- **通信履歴メタデータ**：話者名・時刻・通信種別の表示。
- **共通通信アイコン**：発話者・履歴の暫定アイコンをプロジェクト共通のアイコンデザインへ置き換える。
- **画面寸法と応答性**：狭い画面でパネル内の情報をどのように折りたたむか。初期実装は解像度に応じて伸縮する。
- **状態判定と将来の機能停止**：現在HPが0以下の大破状態と、個別部位・機能停止の関係。

## 9. 判定例・実装上の確認事項

- 2機大破かつ他条件も該当する場合は赤状態を表示する。
- 小隊内の2機以上で盾HPが0なら、赤条件に該当しない限り黄状態を表示する。
- 全機の残存率がちょうど70%の場合、残存率条件による黄状態にはしない。
- 全機の残存率がちょうど40%の場合、残存率条件による赤状態にはしない。ただし、他の赤条件を満たす場合は赤状態とする。
- 最大HPと最大盾HPの合計が0なら残存率は `N/A` とし、残存率の閾値判定から除外する。大破数と盾全損数の判定は行う。
- 最大盾HPが0の盾未装備機は盾全損数に含めない。
- 残存率判定は有効な残存率データを持つ機体が1機以上いる場合にのみ行う。
