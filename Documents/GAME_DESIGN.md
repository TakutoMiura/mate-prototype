# MATE小隊RTS — ゲームデザイン概要

- 版: 0.2 / 認識合わせ用草案
- 状態: 確定事項・提案・未決定事項を区別する。**この文書だけを根拠に未決定事項を補完実装しない。**

## 1. 企画意図

本作は『フロントミッション オルタナティヴ』ライクな、**小隊指揮型リアルタイム戦術ゲーム（RTS）**である。この作品名はプレイ感覚を説明する参照に限り、原作仕様の再現を要求しない。以降の実装判断は本プロジェクトの仕様を優先する。

プレイヤーは個々の機体を直接操縦せず、複数小隊へ進軍経路、交戦方針、標的を指示する。各機はその命令範囲内で射撃・追撃・回避・防御などを自律判断する。**自動化すべき局所操作**と、**プレイヤーが決める戦術的経路**を明確に分ける。

## 2. 用語

- **MATE**: Mobile Articulated Task Equipment。本作の歩行機械の呼称。
- **小隊**: 原則3機のMATEで構成する指揮単位。
- **小隊ポイント**: 各機の実位置から導出する、経路を構成するための仮想的な代表座標。仮想小隊長や各機の拘束目標ではない。
- **ウェイポイント**: プレイヤーが指定する進軍経路上の通過目標。
- **交戦アンカー**: 交戦開始時点の小隊ポイントを凍結して記録した座標。交戦中の行動範囲を規定する基準であり、戦闘後の集合地点ではない。
- **BLOCKED**: 指示された経路・移動アクションを実行できない状態。理由を表示できるようにする。

## 3. ゲームループと操作方針

1. プレイヤーは小隊を選択し、必要に応じ戦術ポーズ中にウェイポイントを設定する。
2. 小隊が進軍し、MATEが隊形・障害物・隘路に応じて局所的に動く。
3. 交戦方針に応じ、遭遇敵への攻撃・追撃、索敵・注視、盾防御・バーニア回避が起きる。MOVE中は索敵しても攻撃しない。
4. 交戦状態から離脱したら、現存機体の現在位置から小隊ポイントと残存経路を再構成して進軍を続ける。**旧交戦地点に集合し直さない。**

操作の規範仕様は `INPUT_SPEC.md` に定義する。既存実装のキー配置は仕様の根拠としない。

## 4. 体験上の柱

- **小隊の計画性と個機の自律性**: 同一小隊でも各機は戦闘中に異なる行動を取る。
- **地形が戦術に作用する**: 隘路、障害物、段差、ジャンプ可能接続、回避空間、射線が意味を持つ。
- **回避と盾防御の使い分け**: 機体は攻撃を外させる・自らかわす・盾で受ける、という結果を区別する。
- **武器に異なる性格**: メインアームは基本的な命中・回避判定、バックユニットは将来的に弾道・範囲・誤射などの個性を持たせる。

## 5. 将来構想（現時点では実装必須でない）
